# Agentic AI Blog Writer

A multi-agent AI content generation system built using **LangGraph**, **FastAPI**, **Angular**, **Ollama**, **Gemini**, and **GPT**.

The project demonstrates how to orchestrate multiple specialized AI agents that collaborate to research, analyze, plan, generate, edit, and evaluate technical blog content.

Rather than relying on a single LLM call, the workflow decomposes the task into multiple specialized agents connected through a LangGraph workflow.

---

# Architecture

```text
[Topic Input]
      │
      ▼
🔍 Research Agent
      │
      ▼
🧠 Research Analyst Agent
      │
      ▼
📝 Planning Agent
      │
      ▼
⚡ Parallel Writer Agents
      ├── Writer A
      ├── Writer B
      ├── Writer C
      └── Writer D
      │
      ▼
📄 Editor Agent
      │
      ▼
⚖️ Judge Agent
      │
      ▼
[Final Blog]
```

# Current Limitations

* Content quality depends heavily on research quality.
* No persistent memory.
* No checkpointing.
* Human-in-the-loop workflow not implemented.
* Single-session execution.
